# Parallax Animations — Paroller.js & Parallax.js Demo

Демо-страница с параллакс-анимациями для портфолио.

- **Parallax.js** — эффект глубины в hero-блоке при движении мыши.
- **Paroller.js** — плавный параллакс при прокрутке для фона и foreground-элементов.
- Адаптивный тёмный дизайн, акцент на визуальный сторителлинг.

## 🔗 Live Demo

👉 [Открыть демо](https://marinalovesjs.github.io/parallax-animations/)

## ⚙️ Использованные технологии

- HTML5, CSS3
- JavaScript (Vanilla)
- [Parallax.js](https://github.com/wagerfield/parallax)
- [Paroller.js](https://github.com/tgomilar/paroller.js)

## ✨ Особенности

- Hero-секция с многоуровневым параллаксом.
- Плавный скролл к блокам ниже по клику на кнопку.
- Paroller.js для:
  - фона секции (background parallax),
  - плавающего блока с текстом (foreground parallax).

---

Собрано в рамках практики по анимациям и эффектам прокрутки.
